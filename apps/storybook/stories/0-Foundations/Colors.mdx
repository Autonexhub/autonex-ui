# Color System

Design tokens for the Marta dashboard. All colors are CSS custom properties defined in `index.css`.

**Source of truth: the Autonex Design System** (brand DS, Claude Design). The panel uses the
same palette as marketing — white canvas, ink near-black and the official Autonex blue — so
product and brand read as one.

**Neutrals (decisión Bruno 02/09):** la escala de grises del panel es **neutra** (sin tinte cálido)
y la tinta es `#161617`. Más contraste en texto secundario y bordes más definidos — donde más se
nota es en las tablas. Pendiente de reflejar en el DS de marca.

**`--ai`** (decisión Bruno 02/09) es el color semántico de todo lo que genera el agente IA: morado
sereno `#7532DD`, de la misma familia de intensidad que success/warning/destructive. Los `chart-*`
siguen reservados a gráficas.

For small blue **text** on white, use the darker step `#2461DB` (brand DS `blue-600`) to keep
AA contrast; `#2F75FF` is for fills, icons and large text.

**`--ring`** is not a fill color: it is the **focus color** — the solid brand blue `#2F75FF`,
always used with an opacity modifier as a halo around the focused control (e.g.
`focus-visible:ring-2 ring-ring/30`). Never use it as a background.

## Usage Rules

- **Brand blue** (`#2F75FF`): Max 1 element per screen (active menu, CTA button)
- **Grey** (`#F5F5F5`): only in subtle zones — search bar, input fills, active sidebar item. The canvas stays white.
- **Charts**: Use chart-1 through chart-6, never brand blue
- **Status colors**: Green = OK, Red = error, Amber = warning, Gray = neutral
- **No hardcoded colors**: Always use CSS variables
